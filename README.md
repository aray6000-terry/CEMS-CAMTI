# 合約設備管理與數量統計系統 (18家公司獨立分頁 + 5大系統 + Google Sheet 多工作表串接)

專為多公司/多建案合約設備設計的現代化管理與查詢系統，提供 **18 家公司獨立專屬分頁**、**5 大弱電與智慧安防系統** 獨立統計、多層級帳號權限管理 (RBAC)、各型號各年度交貨預測報表，以及直接串接 **Google Sheet (每家公司獨立工作表)** 作為雲端即時資料庫的功能。

---

## 🌟 核心特色

### 1. 18 家公司獨立專屬分頁 (Multi-Company Dedicated Tabs)
系統於頂部提供專屬公司分頁導覽列，支援即時統計切換與獨立資料檢視：
1. **宗亞**　2. **宗鈺**　3. **宗泰**　4. **資訊星**
5. **宗群**　6. **宗友**　7. **宗晟**　8. **和興**
9. **宗科**　10. **宗順**　11. **宗益**　12. **百成**
13. **宗麒**　14. **廣晟**　15. **宗榮**　16. **宗霖**
17. **優德美科技**　18. **富鈺節能科技**
*   **點擊分頁即時切換**：頂部 8 大 KPI 指標、5 大系統項數、設備清單與 3-5 年預測報表皆依當前選定之公司即時過濾與計算。
*   **全部公司總覽**：管理員可一鍵切換回「全部公司」查看跨公司加總統計。

### 2. 5 大系統專屬分類與統計 (5 Major Systems)
系統嚴格劃分並提供專屬圖示、主題色與即時數量統計：
1. **對講機系統** 📞：觸控門口主機、室內緊急對講分機、管理總機、防爆工業對講機等。
2. **攝影機系統** 📹：4K防暴半球、360度全景魚眼、AI熱成像球機、NVR錄影主機等。
3. **門禁系統** 🚪：人臉/指紋/悠遊卡多頻主機、非接觸出門按鈕、掌靜脈辨識、快速三叉閘門。
4. **電子鎖系統** 🔐：斷電開型陽極鎖、高磅數磁力鎖、窄版陰極鎖、智慧防盜電子鎖。
5. **燈控系統** 💡：數位智能調光模組、多迴路繼電器模組、DALI-2 控制閘道器、感測控制器。

### 3. 系統帳號中心 (登入與申請新帳戶)
*   **登入系統**：支援使用者帳號與密碼驗證。
*   **申請新帳戶**：線上填寫帳號、姓名、密碼、電話與信箱即可快速建立帳號並登入。
*   **16 家公司完全開放存取**：所有使用者均可自由切換並管理 16 家公司的設備資料。

### 4. 各系統、各型號之各年度交貨與未來 3-5 年預測報表 (Annual Forecasting)
*   **各型號年度查詢**：支援依「公司分頁」、「系統分類」與「品牌型號 (Model)」維度查詢歷年與未來 3-5 年 (2026-2030) 數量與交貨排程。
*   **已交貨 / 未交貨多維度篩選**：可單獨查看已交貨數量、未交貨待點交數量，或合計總數量。
*   **高品質 SVG 視覺化圖表**：動態繪製年度分組柱狀圖，區隔歷史實績與未來預測走勢。
*   **矩陣明細表與 CSV 匯出**：完整列出各型號各建案各年度交貨數量，支援一鍵匯出 UTF-8 BOM CSV 報表。

### 5. 欄位架構與語意
*   **建案名稱 (`project_name`)**：明確標註所屬工程或建案（如：竹科P1晶圓廠新建工程、信義智慧科技園區）。
*   **業務人員 (`sales_rep`)**：建案/工程所屬業務負責人員（如：陳業務專員、王業務副理）。
*   **交貨狀態 (`delivery_status`)**：`已交貨`（綠色徽章）/ `未交貨`（琥珀色徽章）。
*   **數量明細**：包含 `合約總數量`、`已交貨數量` 與 `未交貨數量`，並支援表單自動扣抵計算。
*   **備註 (`remarks`)**：記錄交貨驗收、安裝細節與排程說明。

## 🚀 快速開始使用

### 方式一：啟動本機伺服器 (推薦)
1. 雙擊執行目錄下的 `啟動本機伺服器.bat`（或在終端機執行 `node server.js`）。
2. 在瀏覽器開啟：`http://localhost:5173` 即可立即使用。
3. 點擊右上角 **「登出」** 或 **「登入 / 註冊」** 即可呼叫系統帳號中心。
4. 點擊上方 **「3-5年年度報表」** 按鈕可切換至各系統各型號的年度交貨預測分析圖表。

## ☁️ Google Sheet 雲端資料庫串接指南

1. **新建 Google 試算表**：在 Google Drive 新增一份空白的 Google Sheet。
2. **開啟 Apps Script**：點選上方功能表的 **「擴充功能」->「Apps Script」**。
3. **貼上後端程式碼**：
   - 清空預設內容，將本專案 `google-apps-script/Code.gs` 的所有程式碼貼入。
   - 儲存專案 (Ctrl + S)。
4. **部署為網頁應用程式 (Web App)**：
   - 點選右上角 **「部署」->「新增部署作業」**。
   - 齒輪圖示選擇 **「網頁應用程式 (Web App)」**。
   - **說明**：設備管理與交貨統計 API
   - **執行身分**：我 (您的 Google 帳號)
   - **誰可以存取**：**任何人 (Anyone)** *(重要：若選僅限自己會造成跨網域無法讀取)*。
   - 點擊「部署」並授權存取。
5. **綁定至前端系統**：
   - 複製部署完成後產生的 **「網頁應用程式網址 (Web App URL)」**。
   - 目前已配置之 Web App 網址：`https://script.google.com/macros/s/AKfycbwmyzhEWhd9ADvJ4LZe-GIwelQERa696zuRUsJMMZcQwc087z-AvW5AHkLIMjSBrXrL3A/exec`
   - 回到本系統網頁，點選右上角 **「雲端串接」**。
   - 貼上網址並點擊 **「測試 API 連線」** -> **「儲存並連線」**。
   - 系統將自動在 Google 試算表中建立 `Users`、`Companies`、`Logs` 與 16 家公司專屬工作表分頁並同步資料！
